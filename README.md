# L4D2-Player-Skills

Plugin SourceMod para Left 4 Dead 2 que detecta y anuncia jugadas competitivas
y expone eventos y resúmenes de ronda a otros plugins. Usa eventos del motor
y hooks de Left4DHooks.

## Inicio rápido

Instala Left4DHooks y extrae el ZIP en `left4dead2/`. Usa `sm_skills` para
consultar un jugador y `sm_skills_stats` para comparar equipos.

Consulta la [configuración y los comandos](docs/usage/README.md), la
[API](docs/api/README.md) y el [índice de documentación](docs/README.md).
La [validación](docs/validation/README.md) describe los resultados locales
y los escenarios pendientes en SRCDS.
